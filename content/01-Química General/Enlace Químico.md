# 🔗 Enlace Químico

Un enlace químico es la fuerza que mantiene unidos a los [[01-Química General/Átomo|átomos]] para formar moléculas o cristales.

---

## Tipos de enlace

### 1. Enlace iónico

| Característica | Detalle |
|---|---|
| **Entre...** | Metal + No metal |
| **Mecanismo** | Transferencia de electrones |
| **Ejemplo** | NaCl (sal común) |
| **Propiedades** | Sólidos cristalinos, alto punto de fusión, solubles en agua |

### 2. Enlace covalente

| Característica | Detalle |
|---|---|
| **Entre...** | No metal + No metal |
| **Mecanismo** | Compartición de electrones |
| **Ejemplo** | H₂O, CO₂ |
| **Propiedades** | Puntos de fusión variados, pueden ser polares o apolares |

### 3. Enlace metálico

| Característica | Detalle |
|---|---|
| **Entre...** | Metal + Metal |
| **Mecanismo** | "Mar de electrones" deslocalizados |
| **Ejemplo** | Fe, Cu, Al |
| **Propiedades** | Conductividad, maleabilidad, brillo |

---

## Electronegatividad y tipo de enlace

La diferencia de electronegatividad entre dos [[01-Química General/Tabla Periódica|elementos]] determina el tipo de enlace:

| Diferencia | Tipo de enlace |
|---|---|
| 0 - 0,4 | Covalente apolar |
| 0,4 - 1,7 | Covalente polar |
| > 1,7 | Iónico |
