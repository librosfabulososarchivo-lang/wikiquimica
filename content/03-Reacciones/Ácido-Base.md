# 🧪 Reacciones Ácido-Base

Una reacción ácido-base ocurre cuando un ácido y una base se neutralizan entre sí.

---

## Teorías

| Teoría | Ácido | Base |
|---|---|---|
| **Arrhenius** | Libera H⁺ en agua | Libera OH⁻ en agua |
| **Brønsted-Lowry** | Dona H⁺ (protón) | Acepta H⁺ |
| **Lewis** | Acepta par de e⁻ | Dona par de e⁻ |

---

## La escala de pH

| pH | Clasificación | Ejemplo |
|---|---|---|
| 0-6 | Ácido | Zumo de limón (2), vinagre (3) |
| 7 | Neutro | Agua pura |
| 8-14 | Básico | Amoniaco (11), lejía (13) |

**pH = -log[H⁺]**

---

## Neutralización

```
Ácido + Base → Sal + Agua
```

Ejemplo: **HCl + NaOH → NaCl + H₂O**

---

## Ácidos y bases fuertes vs débiles

| Tipo | Característica | Ejemplo |
|---|---|---|
| **Ácido fuerte** | Se disocia completamente | HCl, H₂SO₄ |
| **Ácido débil** | Se disocia parcialmente | CH₃COOH (acético) |
| **Base fuerte** | Se disocia completamente | NaOH, KOH |
| **Base débil** | Se disocia parcialmente | NH₃ |
