# 🧬 Grupos Funcionales

Un grupo funcional es un átomo o conjunto de átomos que, unidos a un [[02-Química Orgánica/Hidrocarburos|hidrocarburo]], le confieren propiedades químicas específicas.

---

## Principales grupos funcionales

### Alcoholes (R-OH)

```smiles
CCO
```

Etanol — el alcohol de las bebidas. Terminación **-ol**.

### Aldehídos (R-CHO)

```smiles
CC=O
```

Etanal. Terminación **-al**.

### Cetonas (R-CO-R')

```smiles
CC(=O)C
```

Propanona (acetona) — disolvente de esmalte de uñas. Terminación **-ona**.

### Ácidos carboxílicos (R-COOH)

```smiles
CC(=O)O
```

Ácido etanoico (acético) — el del vinagre. Terminación **-oico**.

### Aminas (R-NH₂)

```smiles
CN
```

Metilamina. Terminación **-amina**.

---

## ¿Por qué importan?

Cada grupo funcional determina:

- **Reactividad:** cómo reacciona la molécula en una [[03-Reacciones/Ácido-Base|reacción ácido-base]]
- **Propiedades físicas:** punto de ebullición, solubilidad
- **Función biológica:** los alcoholes, ácidos y aminas son esenciales en seres vivos

---

## Interconversión: de un grupo a otro

```
Alcohol ──oxidación──→ Aldehído ──oxidación──→ Ác. carboxílico
    │
    └──deshidratación──→ Alqueno
```

Las [[03-Reacciones/Redox|reacciones redox]] son clave para transformar unos grupos en otros.
